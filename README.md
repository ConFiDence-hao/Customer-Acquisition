## 开发启动

需要 Python 3.12。在仓库目录执行：

```powershell
python -m venv .venv
.venv/Scripts/Activate.ps1
pip install -r requirements.txt
python -m playwright install chromium
$env:RADAR_PASSWORD = Read-Host '设置本地管理员初始密码（至少12位）'
$env:SESSION_SECRET = [guid]::NewGuid().ToString() + [guid]::NewGuid().ToString()
$env:SCHEDULER_ENABLED = 'false'
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000 ，账号 admin，使用上面设置的密码。环境变量在启动前设置；直接 uvicorn 启动不会自动读取 .env。默认本地 data/radar.db 独立保存数据。

浏览器依赖已固定在requirements.txt；新环境需安装Playwright Chromium。Windows也支持回退到已安装的系统Edge，使用独立后台浏览器上下文，不读取用户Chrome登录态。Dockerfile已加入浏览器系统依赖及OCR所需libgl1；提交948007c已于2026年10月16日在178构建部署，运行时通过compose.override.yaml提高浏览器/OCR的资源上限。仓库原始compose.yaml保留旧限制，部署时应结合下文记录。

```sh
python -m pytest tests -q -p no:cacheprovider
```

2.2.1 部署时85项回归测试通过。测试使用独立测试数据，开发时不要连接生产数据库。企业名录属于业务数据，不纳入仓库；缺少 seed/companies.json 时可空库启动。需要实际名录请单独申请授权提供。

前版浏览器/OCR续更的全量Python验证为687项通过，后续80项边界定向测试通过，JavaScript测试28项通过；这些是本次文字优先/PDF部分保留调整前的历史记录，定向数量不与全量结果相加。Docker镜像尚未构建验证。上述85项保留为原始发布历史。

## 代码结构

- app/main.py：HTTP接口、认证与生命周期。
- app/db.py、accounts.py、workbench.py：数据库、账号、订阅推送和自动任务。
- app/collectors.py、monitoring.py：采集调度、公共访问边界与自定义监测；procurement_sources.py、public_resource_sources.py、industry_sources.py 为分站解析规则。
- app/browser_fetch.py、bidi_sources.py：有预算的普通浏览器读取及比地公开根栏目；image_ocr.py处理允许读取的三峰图片正文；pdf_content.py处理公开PDF原生文字及扫描页本地OCR；robots_rules.py实现robots规则匹配；source_health.py把运行问题映射为固定公开说明。
- app/static/：工作台页面、交互与样式。
- tests/：回归测试。
- .env.example：配置示例，无真实凭据。

## 当前开发分支的数据与权限设计

- 日常工作区为今日资讯、推送列表和我的跟进。系统配置中的订阅情况、自动化任务默认展示概览，通过新建/编辑订阅和配置任务按钮打开表单弹窗；普通账号只配置个人推送，管理员另有公共网站采集计划。
- 每个账号首次补齐四个个人订阅：智慧焚烧与燃烧优化、烟气净化与排放提标、自动化控制与智慧管控、飞灰处置。已有同名订阅保留个人配置，新账号创建时获得默认主题；初始化记录独立保存，重启不会恢复已修改、停用或归档的主题，也不会覆盖已有订阅。四个预置主题不占用50个自建订阅的限额。默认关键词按已确认的业务分组填写，地区、来源及公告阶段不限；当前匹配仍为关键词包含规则，尚无语义模型判定。
- 监测网站目录登记28个入口，普通账号可分类、搜索及筛选接入状态。当前已注册并启用16个来源适配，新增比地公开招标预告、招标公告和采购意向根栏目规则；“16个适配”不等于“16个网站当前都能读取”。比地本机匿名浏览器遇IP安全认证，尚未实测接通。旺能属于前期公示，采招限公开项目概况和报名须知，会员联系方式不采集。新库默认启用已适配来源；既有数据库的配置和管理员停用状态不会因重启被覆盖，新增适配需明确启用。其他入口附核验原因与覆盖范围；登记网址不会自动生成采集规则。公开目录只返回展示字段，管理规则、原始错误和认证信息仍仅管理员可访问。
- 管理员维护可采集的网站、提取规则和公共推荐策略。启用账号的有效订阅关键词会按所选来源补充内置网站的后续检索和入库筛选；个人排除词只作用于自己的主题，全局排除词仍作用于内置采集。自定义网站沿用管理员配置的站点规则。
- 关键词不能补出网站本身没有的数据。支持检索的来源按采集轮次分批查询超额关键词；同一轮发现的公开公告去重后进入共享资讯库，再由各账号的订阅推送任务匹配。
- 新增或修改订阅、启用订阅及启用个人推送计划会登记一次后台检查请求；任务和运行调度启用时，在下一次调度检查（通常15秒内）匹配已有公共资讯并生成首批站内推送，之后按配置间隔继续检查。请求持久保存，重启或失败不会丢失；停用账号或计划不会执行。推送过程中规则发生变化时放弃旧结果并重查，同一账号同一公告仍只推送一次，已有首次送达和阅读状态保留。首次真实检查成功后才更新执行时间，不通过修改历史执行时间来催任务。
- 管理员保留自己的订阅、推送计划、推送列表和我的跟进。管理员专属团队看板分为订阅运行与跟进进展，展示团队主题、来源可用性、匹配与推送统计，以及已领取公告的负责人和公开阶段；不展示员工的私人备注、专题 AI 解读或已读记录。
- 团队看板区分无启用来源、当前暂无匹配、账号或主题停用、个人推送停用。零匹配需要结合后续采集、网站覆盖和规则核查，不代表市场上没有相关项目。
- 浏览、AI 研判和保存个人研判不会自动领取公告。员工主动点击“开始跟进”后，同一公告只有一位团队负责人，姓名、公开阶段和更新时间对团队可见；备注始终归本人。负责人可以放弃，管理员可以转交给启用账号，转交保留已有公开阶段，不复制或修改接手人的私人记录。
- 我的跟进汇总本人保存的个人研判和当前负责的公告。同一公告在今日资讯、推送列表和我的跟进中共用个人记录与团队负责人信息；原有私人记录不会自动变为公开跟进。

## 公开采集链路与限制

网站自动采集任务按管理员配置的周期读取已启用来源；各站使用已核验的公开列表、网站公开查询接口、公开PDF或普通浏览器渲染后的公开页面。三峰图片型正文在原图允许自动读取时可进行本地OCR；北极星仅保留网页文字，不下载公告图片、不进行其图片OCR。系统不执行登录、不读取用户Chrome登录态、不自动完成访问验证、不抓取会员隐藏字段。推荐策略中的行业词、重点词和全局排除词仍参与标题候选筛选；启用账号的个人订阅关键词扩展候选范围，来源限制与个人排除词仍保留。中节能支持轮换关键词检索，其他内置来源主要读取有限栏目和分页，因此不是全站遍历，也不是每个主题都会搜索各站全部历史数据。

候选逐条读取正文和原网站发布元数据，按URL去重保存到公共SQLite库，保留首次采集、最近检查和内容版本。成功读取的正文缓存6小时，列表每轮仍检查；详情暂不可读时保留历史正文或标注“仅列表线索”，不会将导航或验证页面入库为正文。原网站只有日期就保留日精度，仅相对时间或缺少年份则发布时间未知，不用采集时间填补。跨网站转载使用不同URL仍可能出现多条，当前不做跨网站语义去重。

正文缓存使用独立的列表原标题和来源渠道核对，不用详情页标题或首次来源替代缓存条件；列表日期变化时仍核对已取得的正文日期，保留冲突提示。每个内置来源的执行详情记录耗时、实际HTTP尝试次数、正文缓存命中数和详情读取数，便于定位采集耗时；实际HTTP次数包含重试，不等于发现的公告数量。

个人订阅推送任务独立扫描公共库，按关键词包含匹配和地区、来源、阶段等条件生成站内推送；采集与推送不是同一个任务，也不依赖大模型。列表正常但零条符合筛选条件是正常结果；“部分可用”可由补页、详情、原图规则或预算限制引起，不等于整个网站没有阅读权限。公开状态现在区分IP安全认证、需要登录、浏览器组件未就绪、浏览器预算耗尽、原图禁止自动读取、OCR失败等固定原因，不公开管理员原始错误、密钥或私有规则。

本轮正文覆盖调整：首创公开PDF先逐页提取原生文字，扫描页使用本地OCR；最多处理前30页，输入不超过20,000,000字节（20MB），输出最多65,000字符，提取进程总预算90秒。部分页失败或超时仍保留已经完成的页，界面标明读取页数、OCR页数、已知失败页及截断原因，并提供来源原文链接；没有取得的信息保持未知。首创旧入库158795.html《宁河污水厂区房顶防水服务项目》中标结果公告已完成真实1页扫描PDF验证：总页数、读取页数、OCR页数均为1，coverage为complete，本地OCR成功；另用合成31页原生PDF验证只取前30页并标明截断，不能把该合成测试写成真实网站31页样本。大同从已核实正文容器保留真实短文本；没有正文也保留公开列表标题、网址、已取得的发布日期与来源，不伪造采购主体、预算或期限。

本地第47轮为北极星两栏目、首创和大同各一条已入库线索的定向详情复核，共4条更新，不是完整四站采集。垃圾发电样本为partial，公告图片未下载、未OCR；固废样本完整可读；首创扫描PDF完成OCR；大同短正文为partial且可读。证据位于 .venv/local-proof/pdf-partial-20261015/ 的 proof.json、31-page-proof.json、local-verification.json，不代表相关网站所有公告均已取得完整正文。

单条公告用content_coverage区分complete（按当前采集规则取得正文）、partial（仅取得部分内容）和list_only（仅列表线索）。partial不代表整站访问失败；来源访问、验证、robots和补页问题另记。每条详情都有“项目摘要（规则生成）”“推荐依据（规则评分）”和“事实证据”区块，证据不足显示未知或待核实；这些不依赖模型调用。另行生成的公共AI解读显示模型与生成时间。公共自动AI仍只处理85分及以上、尚无公共解读的公告，每轮最多5条；有权限的手动AI、专题AI和跟进项目AI各走原有触发与授权，不受该公共自动阈值限制。

前版浏览器与图片读取已取得以下历史证据：三峰id=301的会议纪要由3张图片组成，本地OCR取得1320字符；北极星固废样本 https://huanbao.bjx.com.cn/news/20260928/1514469.shtml 通过普通浏览器取得1606字正文，该页原公告发布时间为2026-09-28 09:41，09:41不是核验时刻。北极星垃圾发电样本 https://huanbao.bjx.com.cn/news/20261013/1516004.shtml 的网页文字较少，图片由img01.mybjx.net提供，当时遇原图robots限制；本轮已改为仅留网页文字，图片内容由使用者查看原文。这些是单条历史样本结果，不代表相关来源全部正文均已接通。比地已注册3个公开根栏目规则，但匿名浏览器被IP安全认证拦截，尚无实测接通结论。

默认每来源最多渲染40个页面，浏览器网络请求上限500次；静态HTTP客户端的500次调用预算独立计算。图片OCR单篇最多6图、每图4MB、总计12MB，OCR子进程最长30秒、单篇总预算45秒，CPU识别使用1线程。达到限制后保留已有线索并标明具体原因。原图域名也独立检查robots；网页能在浏览器显示，不代表其图片可以自动下载。

其余28站逐站结论保留在交付文档中的“第35轮历史快照”，不作为本次全站重新核验结果。旧记录中的“北极星正文验证”“三峰1条正文不足”和“比地未接入”应结合上述续更阅读；中国招投标公共服务平台、吉林、瀚蓝等旧访问限制也不能未经新证据改写为已恢复。
