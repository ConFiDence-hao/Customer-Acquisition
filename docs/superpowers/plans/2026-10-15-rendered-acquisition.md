# 浏览器采集与图片正文 Implementation Plan

> **For agentic workers:** 使用 test-driven-development 和 verification-before-completion；在当前用户指定的本地工作区执行。

**Goal:** 接通比地公开列表与详情、尝试北极星浏览器正文、识别三峰图片正文，并展示网站具体故障。

**Architecture:** 原 HTTP 采集保持主路径；新增可复用的限量 Chromium 渲染器和本地 CPU OCR。各站适配仍经过公开链接校验、robots、限速、缓存和去重。出现可见登录或验证时终止该详情链路并显示原因。

**Tech Stack:** FastAPI、httpx、Playwright Chromium/Edge、RapidOCR ONNXRuntime、pytest。

**Spec:** 用户本轮明确要求；只操作本地服务，不更新生产。

## 执行与验证

- [x] 浏览器运行器：验证公开 URL、重定向/资源边界、可见验证识别、浏览器不可用、渲染预算和进程释放；失败测试后实现。
- [x] 比地适配：从真实 DOM 读取公开栏目、公告标题链接日期及正文；不猜分页、不取会员隐藏字段，测试列表与正文边界。
- [x] 三峰 OCR：仅图片正文调用，限定图片数、文件体积和运行时间；保留图片来源与识别标记，测试错误退化。
- [x] 状态说明：公共接口使用固定安全文案，区分验证码、登录、图片 OCR、正文缺失、翻页失败、停用和未适配；测试隐私。
- [x] 集成后运行针对性及全套回归；对比地、北极星两栏和三峰做真实有限采集，记录实际成功与限制。
- [x] 备份本地数据库、精确启用新增适配并重启本地服务；更新网站核验清单和运行说明。

## 重点边界

隐藏的登录模板不能误判为可见验证；可见访问门槛不能当作正常正文。失败时保留旧正文和已取得列表。OCR 内容不冒充网页原生文字，也不从正文推断发布日期。后台浏览器使用独立临时会话，不读取用户浏览器密码和登录态。既有管理员主动停用配置不自动覆盖。

## 验收结果

本地第45轮（北京时间2026-10-15 10:08:20—10:09:58）：三峰31条候选、30条正文缓存、1条图片正文OCR完成；北极星两频道各5页、250条候选（存在重复）、各4个实际渲染页面，取得可用文字正文，部分图片受CDN robots限制。比地浏览器适配与安全边界已实现，但当前采集机被IP安全认证拦截，真实列表/正文尚未接通；该项外部限制保留，不能据测试通过视为接通。

本地数据库已备份，服务已重启且健康接口200；管理员及xyh的来源目录均显示具体问题。全套Python 687项通过、后续边界定向80项通过，JavaScript 28项通过。Dockerfile准备了运行依赖，容器构建及生产178未执行。
